Token Launch Radar — a dashboard that ranks 198 launch candidates from the 758 protocols in DefiLlama's sealed snapshot by the implied value of a token they have not issued yet, with a concrete farm plan for each one.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

## How it works

`main.ts` (Node 22, standard library only, no network) reads the sealed snapshot
and writes `board.json` (198 ranked rows), the dashboard's data, and `dossier.json`.

**Value model** — implied value = `TVL × category ratio × momentum × age × chains`:

- **Category ratio**: the median market-cap/TVL of the tokenised protocols in the
  same category (at least 3 of them), else the global median (0.169).
- **Momentum**: the 7-day TVL change, clamped to −50%…+100%, mapped to 0.75…1.50.
- **Age**: days since DefiLlama first tracked the protocol, capped at 730 days,
  mapped to 1.00…1.25.
- **Chains**: 1 + 0.03 per extra chain, capped at 5 extra chains.

**Candidate rule** — a protocol is ranked only when the snapshot records no token
at all (market cap, CoinGecko id and ticker all null), and never a bridge, exchange,
liquid-staking product, wrapped or staked product, or versioned deployment. The
40-protocol watchlist is the floor: all 40 are ranked, plus the 158 eligible
protocols below the $50M floor with the most TVL. Protocols that record a ticker
but no market cap (CAKE, MORPHO, ENA and the like) already have a token, so they
are shown in the dashboard's reference panel, never ranked.

**Farm plans** — generated by `dashboard/farm.js`, shared by `main.ts` and the
dashboard, so the steps a reader sees are the steps `board.json` holds. Each plan
is built from the protocol's category (the core action), its main chain (bridge
cost and time) and its rank (position size: $1,000 top 25, $500 to rank 100,
$100 after).

## Layout

- `main.ts` — the entrypoint: snapshot in, board + dashboard data + dossier out.
- `dashboard/` — `index.html`, `app.css`, `app.js`, `farm.js`; `data.js` is
  generated by `main.ts` at run time.
- `screenshots/` — board, detail and filtered views of the dashboard.
- `vendor/makefun-board.ts` — make.fun's dossier library, copied verbatim.
