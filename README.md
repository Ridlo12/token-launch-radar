# Token Launch Radar

A radar for protocols that still record no token, ranked by what their launch
would be worth — each with the steps to farm it.

## What it does

`main.ts` reads the sealed DefiLlama snapshot (`/input/snapshot.json`), finds
the protocols that record no token and are not wrapped or staked products of
one that trades, and ranks them by an implied launch value:

**implied value = TVL × ratio × momentum × tenure × breadth**

- **Ratio** — the protocol's category median market-cap-per-TVL over tokenised
  protocols, winsorized at the 5th/95th percentile and shrunk toward the
  global median (prior weight 5), so a category with one priced peer is pulled
  toward the middle instead of trusting the outlier.
- **Momentum** — 1 + the 7-day TVL change clamped to −60%/+120%, over 150.
- **Tenure** — 1 + 0.45 × √(days listed, capped at 4 years).
- **Breadth** — 1 + 0.03 per extra chain, capped at 5.

The board ranks 197 protocols, including all 40 of the snapshot's watchlist.
Each row carries a 7-step farm plan with an explicit cost and time per step,
generated by `dashboard/farm.js`, which `main.ts` and the dashboard share.

The dashboard (`dashboard/`) is a single static page: a Top-10 spotlight, a
sortable and filterable board, a detail view per protocol with a factor
waterfall and its farm plan, an implied-value-by-category chart, a
concentration panel, and a panel of the already-trading protocols whose
market caps set the ratios. It renders with no network.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```

Node 22 or later, standard library only. The program runs twice and both
runs write the same bytes to `/output` (or `MAKEFUN_OUTPUT_DIR`): `board.json`,
`dashboard/` (with `data.js`), `screenshots/` and `dossier.json`.
